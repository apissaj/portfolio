# hafizhhh.dev

Portfolio pribadi **Hafizh Muzani** — dibangun dengan Next.js 16, Tailwind CSS v4, dan shadcn/ui.

→ Live: [hafizhhh.dev](https://hafizhhh.dev)

## Fitur

- Light/Dark themes
- SEO optimized (JSON-LD schema, sitemap, robots)
- Installable sebagai PWA

## Proyek yang Dipamerkan

- **[Cloud Mail](https://mail.hafizhmuzani.my.id)** — Self-hosted email platform di Cloudflare Workers: catch-all inbox, AI-powered OTP extraction, public API untuk automation.
- **[KoncetCloud](https://kc.koncetcloud.web.id)** — Self-hosted cloud backup & storage manager powered by rclone: multi-remote support, LocalSend receiver, 2FA TOTP, live transfer monitoring.
